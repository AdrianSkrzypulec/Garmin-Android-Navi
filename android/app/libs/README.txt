Garmin Connect IQ Android Mobile SDK
======================================
Aby aplikacja komunikowała się bezpośrednio z aplikacją Garmin Connect Mobile na telefonie:
1. Pobierz "Connect IQ Mobile SDK for Android" ze strony deweloperskiej Garmina:
   https://developer.garmin.com/connect-iq/sdk/
2. Skopiuj plik `connectiq-sdk-*.aar` lub `connectiq-sdk-*.jar` do tego folderu (`android/app/libs/`).
3. W Android Studio kliknij "Sync Project with Gradle Files".
4. Gotowe! Klasy `com.garmin.android.connectiq.*` będą automatycznie powiązane z projektem.
